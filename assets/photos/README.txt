Положи сюда исходные фотографии кофейни в формате JPG или PNG.
Для каждой фотографии добавь объект в photos.json:
- id: уникальный ID, например photo_002
- file: имя файла
- description: что изображено
- category: рубрика
- tags: массив тегов для поиска по смыслу

Файл в photos.json должен реально существовать в этой папке.
